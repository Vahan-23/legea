СИСТЕМА ЦВЕТОВ — РЕАЛИЗУЙ ТОЧНО
═══════════════════════════════════════════════════════════
Коды расцветок Legea имеют формат XXYY, где XX — основной цвет,
YY — цвет отделки и вставок.
  0002 → синий однотонный
  0203 → синий + белая отделка
  1204 → красный + синяя отделка
  0704 → жёлтый + синяя отделка

data/colors.ts — карта кодов:
  01 #F07A1E orange        02 #1E5FD0 royal blue
  03 #FFFFFF white         04 #14204A navy
  05 #5BB8E8 sky           06 #E8388F fuchsia
  07 #F2CF1B yellow        08 #8B1A2B bordeaux
  10 #111111 black         11 #F5B8C8 pink
  12 #D8232A red           13 #1E9B4B green
  14 #6B3FA0 purple        24 #3B9BE8 light blue
  27 #FF5A1F fluo orange   28 #7CFF3D fluo green
  36 #FF2D8F fluo pink     40 #DFFF33 fluo yellow
  44 #B8BCC2 melange grey  75 #2F6F5E deep teal

lib/colorCode.ts:
  parseColorCode(code: string): {
    base: string; trim: string; isSolid: boolean; isIridescent: boolean
  }
  — 4 символа → base = map[0..2], trim = map[2..4]
  — если base === trim → isSolid true, trim = darken(base, 12%)
  — коды 1075 / 2324 / 0476 → isIridescent true (паттерн LUXIOM)

Свотчи в UI: круг; для двухцветных — conic-gradient пополам
(base / trim). Активный свотч с кольцом цвета blue.

3D-СЦЕНА
═══════════════════════════════════════════════════════════
Модели GLB в /public/models/:
  jersey_ss, jersey_ls, shorts, socks, jacket, hoodie,
  pants, gk_kit, ball, backpack, volley_top, basket_top

Каждая модель содержит меши с именами: Base / Trim / Logo.
Перекраска идёт через материалы этих мешей — БЕЗ перезагрузки GLB.
Смена цвета — плавный lerp за 400 мс в useFrame, не резкая.
Смена товара — уменьшение + fade out, появление с GSAP back.out.

Освещение: <Environment preset="studio"> + key light сверху-справа
+ rim light сзади для контура. <ContactShadows> под моделью.

Управление: OrbitControls, enablePan false,
polarAngle [Math.PI*0.25, Math.PI*0.75],
autoRotate 0.4 после 3 секунд бездействия.

Материал ткани: MeshStandardMaterial, roughness 0.85, metalness 0,
normalMap тканевого переплетения, normalScale 0.4.
Для LUXIOM: MeshPhysicalMaterial, iridescence 1, iridescenceIOR 1.8.

ЗАГЛУШКИ: реальных GLB пока нет. Создай PlaceholderModel.tsx —
параметрическая геометрия из примитивов three.js (торс-цилиндр
со скруглением, рукава, воротник), с теми же именами материалов
Base / Trim / Logo, чтобы вся логика перекраски и декалей работала
до подстановки реальных моделей. Загрузчик должен автоматически
подхватывать GLB, если файл существует в /public/models/.

СПЕЦИФИКАЦИЯ (/spec)
═══════════════════════════════════════════════════════════
Это не заказ, а точное техническое задание для менеджера.

Сводка позиций: артикул, название, расцветка (визуальный свотч

Форма (react-hook-form + zod):
  организация*, контактное лицо*, телефон*, email*,
  город*, желаемый срок поставки, комментарий.

Две кнопки:
  «Скачать спецификацию (PDF)» — jsPDF + autoTable:
    шапка с логотипом дистрибьютора и реквизитами,
    номер спецификации и дата,
    таблица позиций без колонки цены,
    превью брендирования картинкой,
    строка «Расчёт стоимости предоставляется менеджером»,
    контакты дистрибьютора в подвале.

  «Получить расчёт» — POST /api/spec:
    письмо менеджеру через Resend с PDF и файлом логотипа
    во вложении, подтверждение на почту клиента.
    После отправки — экран «Расчёт придёт в течение 24 часов»
    с номером обращения.
